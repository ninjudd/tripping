[agent-sdk](https://github.com/ninjudd/agent-sdk) instead of a PTY, behind the
same message interface. Cheaper per teammate, at the cost of the thing that
makes this design worth having — see [`agent-orchestrator.md`](../agent-orchestrator/readme.md) §11.
